## Directory Guide
- **`docs/`** - All documentation and guides
- **`research/`** - Market analysis, competitor research, user studies
- **`prototypes/`** - Working code and proof-of-concepts
- **`workflows/`** - Content transformation workflows and logic
- **`templates/`** - Content templates and formats
- **`assets/`** - Images, examples, and reference materials
