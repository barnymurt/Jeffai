# FAQ Answers

Use this format for responding to frequently asked questions in internal communications.

## Format Structure

**Clear Question Statement** - Restate the question being answered
**Direct Answer** - Lead with the main answer/solution
**Context/Background** - Why this is the policy/process (if relevant)
**Action Steps** - What the person should do next (if applicable)
**Additional Resources** - Where to get more help/info

## Tone Guidelines
- Start with empathy - acknowledge the question/concern
- Be direct and clear - don't bury the answer
- Use simple language, avoid jargon
- Anticipate follow-up questions
- End with next steps or resources

## Template

### Q: [Restate the question clearly]

**A:** [Direct, clear answer to the main question]

[Optional context paragraph: Why do we do it this way? What's the background?]

**What you need to do:**
- [Step 1 if applicable]
- [Step 2 if applicable]
- [Step 3 if applicable]

**Need more help?** 
- Contact [team/person] at [email/slack]
- Check out [resource/link] for more details
- See our [policy/guide] for full information
